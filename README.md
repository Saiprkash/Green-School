# Secret Garden Society of AIPS
Built a website to present information about plants in our school using HTML and CSS, with JavaScript where applicable, and deployed it online using Vercel.
📖 About the Project
The Secret Garden Society of AIPS is a school project that provides information about different plants in an organized and easy-to-read format.
For each plant, the website includes details such as:
🌱 Common name
🔬 Scientific name
🌿 Taxonomic hierarchy
🌍 Origin
💚 Medicinal value
🌳 Characteristics
The project was created to combine web development with learning about plants and biodiversity.

HTML
CSS
JavaScript
✨ Features
Information about multiple plants
Scientific and common names

Simple and user-friendly presentation
